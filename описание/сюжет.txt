ПИТОМЕЦ ФИННИ — СЦЕНЫ, СЮЖЕТ, ГЕЙМПЛЕЙ
Версия: экраны3
Для детей 6–11 лет
================================================================================

Условия:
  - Без облака (всё локально).
  - Календарь с 01.01.2020.
  - Управление: большие кнопки и тап по картинке (не стик, не списки).

Шапка на всех экранах:
  [ дата ] • [ время дня: утро/день/вечер ] • [ нужное ] • [ желаемое ] • [ копилка ]

2. СЮЖЕТ В ОДНОМ АБЗАЦЕ
================================================================================

Ребёнок живёт в Копилкино с енотом Финни. Утро: разложил копилки на
«нужное / желаемое / копилку». Днём: покормил Финни, вышел на улицу,
поработал в своём здании, посмотрел на соседа. Вечером: спать —
календарь перелистывается, Финни говорит, совпал ли план с фактом.
Если копил — на банке появляется капелька.


================================================================================
3. УРОВЕНЬ vs ЭВОЛЮЦИЯ
================================================================================

ОПЫТ ДАЮТ:
  • Корм из холодильника
  • Смена в здании
  • Задание
  • Особый корм (желаемое)

ЗА КАЖДЫЙ УРОВЕНЬ — 1 ОЧКО. Тратится на одну карточку:
  1. Открыть соседний район (снять туман)
  2. Ставка копилки +1% (с 5% до 8%)
  3. +1 слот улучшения здания

--------------------------------------------------------------------------------
 ЭВОЛЮЦИЯ — КАЖДАЯ 3-я СТУПЕНЬ
 (меняется внешность Финни + открывается мир)
--------------------------------------------------------------------------------
 Стадия        | Уровни  | Что открывает
--------------------------------------------------------------------------------
 Малыш         | 1–3     | Рынок, ларёк «Продукты»,
               |         | гостиная + кухня + спальня + ванная
--------------------------------------------------------------------------------
 Подросток     | 4–6     | Спальный район, СТО, жилой дом,
               |         | игровая, автокормушка в магазине дома
--------------------------------------------------------------------------------
 Хозяин        | 7+      | Ещё район, Здоровье / Искусство / Стройка,
               |         | фартук Финни
--------------------------------------------------------------------------------

ВАЖНО: стадия НЕ откатывается, даже если день вышел плохим.

4. ТРИ БАНКИ — ПРОСТАЯ ЛОГИКА
================================================================================

--------------------------------------------------------------------------------
 Банка          | Что в неё кладут
--------------------------------------------------------------------------------
 НУЖНОЕ         | Ежедневное:
 (ежедневное)   |   • корм в холодильник
                |   • закупка товара в здание
                |   • аренда
                |   • зарплата работника
                |   • вода / уход
--------------------------------------------------------------------------------
 ЖЕЛАЕМОЕ       |   • игрушка
                |   • особый корм на опыт
                |   • автокормушка
                |   • мебель
                |   • бантик
--------------------------------------------------------------------------------
 КОПИЛКА        | Цель: мячик 300 / палатка 800 / набор 1500
                | Старт: 5%
--------------------------------------------------------------------------------

РЕЖИМЫ ПРОЦЕНТОВ (без формул на экране):

  ● «Каждый вечер капелька»
      → при сне на банку падает 1 капля на каждые 100 €

  ● «Горсть 1-го числа»
      → ждут календарь, падает сразу пачка

СМЕНА РЕЖИМА:
  Банка трясётся, капли исчезают, счётчик дней = 0.
  Ребёнок видит, зачем не прыгать туда-сюда.

Утром после «Начать день» план банок ЗАПЕЧАТАН.
Класть в копилку можно ВСЕГДА.

5. УХОД ↔ ДЕНЬГИ
================================================================================

--------------------------------------------------------------------------------
 Действие              | Откуда деньги          | Что с Финни
--------------------------------------------------------------------------------
 Корм из холодильника  | нужное, 20 €           | сытость +
--------------------------------------------------------------------------------
 Нет корма             | —                      | грустный глаз, подсказка
                       |                        | «магазин или ларёк»
--------------------------------------------------------------------------------
 Автокормушка          | купить желаемым, 200 € | каждый день ест из нужного,
                       |                        | утро без кнопки
--------------------------------------------------------------------------------
 Особый корм           | желаемое, 40 €         | опыт
--------------------------------------------------------------------------------
 Играть                | нужна игрушка          | настроение
                       | из желаемого           |
--------------------------------------------------------------------------------
 Сон                   | бесплатно              | день +1, бодрость
--------------------------------------------------------------------------------

СВЯЗЬ С БИЗНЕСОМ:
  • Выручка ларька вечером приходит в «доступные».
  • Ребёнок завтра кладёт её в банки.
  • Аренда и зарплата утром САМИ вычитаются из «нужного».
  • Если «нужного» мало — Финни говорит:
      «сначала заработай или переложи из желаемого завтра».


================================================================================
6. КОНКУРЕНТ
================================================================================

В районе — одна «Лавка Сороки» того же типа.
На дверях — ценник.
Боты-человечки идут туда, где ДЕШЕВЛЕ и СВЕТЛЕЕ.

Ребёнок НЕ ломает соседа.
  → Заглядывает в окно.
  → Если очередь у Сороки — снизь цену или купи свет/тележки.


================================================================================
7. УПРАВЛЕНИЕ
================================================================================

  • Финни сам идёт по дороге.
  • Может подойти к двери у здания — появится кнопка «Войти».
  • Дальше откроется своё здание.
  • Если здание рабочее — открывается интерфейс управления.
  • Экран — вид сверху:
      – если это магазин продуктов — будут полки;
      – если это СТО — вместо полок подъёмник для автомобиля.

  • Кнопки ≥ пальца. Одна главная на сцене.
  • Назад — стрелка вверх.
  • Нельзя уйти в минус: кнопка «Купить» серая + текст
      «не хватает 30 €».

             |             |                               | свет, касса-
             |             |                               | самообслуживания

--------------------------------------------------------------------------------

             |             |                               | мебель, охрана
--------------------------------------------------------------------------------
 Стройка     | Хозяин      | Погрузка «сейчас»             | склад, погрузчик, витрины,
             |             |                               | каталог, лаборатория
--------------------------------------------------------------------------------
 Здоровье    | Хозяин      | Осмотр: 3 карточки (игра)     | витрина, кабинет, скорая,
             |             |                               | лаборатория, стационар

НАЙМ:
  стул в комнате → кабинет → «Нанять» / «Пока сам».
  Зарплата — из «нужного» каждое утро.
  После найма персонаж СИДИТ на стуле.
