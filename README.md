# 🦝 Питомец Финни — финансовая грамотность для детей

Мобильная игра-симулятор (Android), которая учит детей финансовой грамотности через игру: ребёнок ухаживает за питомцем-енотом Финни и одновременно строит экономику собственного города — зарабатывает, распределяет бюджет, копит, тратит осознанно и ведёт бизнес.

> Версия 1.0 · Тема: образование / финансовая грамотность · Для детей 7–12 лет

---

## ✨ О проекте

Игра построена вокруг **замкнутого экономического цикла**:

1. Игрок зарабатывает деньги (продажи в магазинах, пассивный доход, задания).
2. Все заработанные деньги попадают в «💼 Мешок».
3. Игрок сам распределяет их по **трём банкам**: 👖 Карман («нужное»), 🚛 Желаемое («хочется»), 🐷 Копилка («только копить»).
4. Карман тратится на жизнь: корм, лечение, закупка товара, найм, зарплаты, магазины.
5. Копилка работает: 5–9% процентов за день и вклад в ЦЕЛИ.
6. Игрок строит магазины, нанимает ботов-работников — боты работают, получают зарплату и **тратят её в магазинах игрока**, возвращая деньги ему.

Ребёнок на практике понимает: сколько заработал → как разделить → на что хватает → почему важно копить.

**Валюта:** ₡

## 🎮 Как играть

### Сцены (панель слева / внизу)

| Сцена | Что делает |
|---|---|
| 🏠 **ДОМ** | Уход за Финни: корм (20₡), лечение (30₡), внешний вид; кнопка «💤 Спать» — новый день (18:00–23:00) |
| 💰 **ПЛАН** | Перетаскивание монет из «Мешка» в 3 банки (Карман / Желаемое / Копилка) |
| 🗺️ **КАРТА** | Мир-район «Рынок»: участки, магазины, боты. Тап по зданию — войти внутрь |
| 🧸 **ИГРЫ** | Игрушки для Финни (тратят «Желаемое»), опыт, уровень развлечений — поднимает процент копилки; PLAY-задания |
| 🎯 **ЦЕЛИ** | Своя копилка-цель, выбор активной цели, вкладки «Цели / Задания / Прогресс» |
| 📈 **ОТЧЁТ** | План-факт дня, история дней, стадии роста Финни |
| 📖 **СПРАВКА** | Правила и подсказки |
| 👨‍👩‍👧 **ВЗРОСЛЫЙ** | Защищено арифметикой: профиль ребёнка, демо-режим, сброс профиля, ЧИТЫ для теста |

### Основные правила

- **Игровое время:** 1 игровая минута = 1 реальная секунда. Рабочий день 10:00–18:00 (магазины открыты), с 23:00 «пора спать» — новый день.
- **Время идёт даже при закрытом приложении** — при возвращении день «догонит» реальное время.
- **Сон — смена дня:** проценты копилки, зарплаты кассиров, сбор отчёта по дню.
- **Банки тратятся по назначению:** корм/закупка/найм/здания — из «Кармана», игрушки — из «Желаемого», «Копилка» только копится и вкладывается в цели.
- **Проценты копилки:** 5% + (уровень развлечений − 1), максимум 9%.

### Бизнес-цикл (магазины)

1. На **КАРТЕ** купите зелёный участок (Ларёк / Стройка / СТО).
2. Войдите в здание тапом.
3. **📦 Закупка** — купите товар у поставщиков (следите за ценой и качеством).
4. **🏷️ Цена** — назначьте цену, оцените спрос.
5. **🧾 Касса** — обслужите ботов-покупателей: пробивайте товар, выдавайте сдачу.
6. **👤 Нанять** — наймите кассира (зарплата 80₡/день) — он продаёт сам, выручка копится в кассе здания, заберите её.
7. **📊 Учёт / Запустить день** — итог дня: выручка, себестоимость, прибыль.

### Мини-игры

- 🧃 **Закупка** — выбор поставщика и количества товара.
- 🏷️ **Ценник** — слайдер цены + прогноз покупателей.
- 🧾 **Живая касса** — продать товар и выдать сдачу.
- 🧹 **Уборка** — тап по грязи (+40₡ награда).

### Как устроен прогресс

- **Дни:** каждый сон = новый день; в конце дня считается план-факт.
- **Цели:** копилка → вклады → цель достигнута.
- **Задания:** сюжетные (планирование, сбережения, покупки) и PLAY (игрушки). Награды в ₡.
- **Стадии роста Финни:** Малыш → Подросток → Хозяин ларька (сумма сбережений + успешные дни).

## 🛠️ Технологии

| Слой | Технология |
|---|---|
| Язык | Kotlin |
| UI | Jetpack Compose (Material 3) |
| База данных | Room (8 сущностей, миграции v1→v9) |
| Настройки | DataStore Preferences |
| Фон | WorkManager (потребности питомца, авто-касса) |
| Навигация | Navigation Compose |

**Основные модули (сценарии):** `ui/screens/*` — ДОМ, ПЛАН, КАРТА, магазины, мини-игры, отчёты; `data/*` — Room/DataStore/часы; `domain/*` — экономика (EconomicEngine, GameRules, BotBrain).

- **Экономика:** единый серверный движок `simulateDay()` + `PassiveSales`; все деньги — реальные транзакции с датой игрового дня.
- **Часы:** `GameClock` — время добегает при закрытом приложении.
- **Боты:** сущности в БД со состоянием и позицией, ходят по карте, работают, покупают.
- **Системные требования:** Android 8.0 (minSdk 26) и выше, любая ориентация (ландшафт/портрет).

## 🔧 Сборка и запуск

**Требования:** Android Studio (JBR JDK 17+), Android SDK.

```bash
# Собрать debug-APK
.\gradlew.bat assembleDebug
# Запустить unit-тесты
.\gradlew.bat testDebugUnitTest
```

Либо откройте проект в Android Studio → **Sync** → **Run** на эмуляторе/устройстве API 26+.

Готовый APK: `app/build/outputs/apk/debug/app-debug.apk`.

## 🧪 Демо-режим и читы

Для быстрой проверки доступны:
- **🧪 Демо-режим** (ВЗРОСЛЫЙ): часы идут в 5 раз быстрее, свободный сон, ежедневное пособие 200₡.
- **ЧИТЫ** (ВЗРОСЛЫЙ): добавить деньги в банки, установить дату/время, повторить обучение.

## 🚀 Идеи развития

- AR-режим: Финни в реальном мире, игра в мячик камерой телефона.
- Гибкие цены на товары, больше видов товаров и магазинов.
- Больше анимаций и наглядное движение ботов по карте.
- Новые районы, конкуренты, жилые дома и аренда, типы ботов, родительский кабинет.
