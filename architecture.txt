1. ОБЩЕЕ
------------------------------------------------------------------------
Продукт: симулятор финансовой грамотности для детей 6-11 лет.
Мир: Копилкино. Питомец Финни (енот) помогает вести бюджет.
Стек: Kotlin + Jetpack Compose + Room + DataStore + WorkManager + Navigation Compose.
MinSdk 26, targetSdk 34, namespace com.example.financialliteracyapp.
Сборка: JDK 21 (Android Studio JBR). Сборка/тесты из консоли — см. AGENTS.md §7.

2. СЛОИ (пакеты app/src/main/java/com/example/financialliteracyapp/)
------------------------------------------------------------------------
2.1 data/
    - AppContainer            — точка входа: создаёт GameRepository + UserPrefs.

4. ЭКОНОМИКА (день)
------------------------------------------------------------------------
- Старт: подарок 500 ₡ (source=starting_gift) + карман 150 ₡/день (daily_allowance).
- План: делит доступные деньги на 3 банки (need/want/save) из WalletEntity.
  План фиксируется после подтверждения; правка — только через сброс дня.
- Покупки: в магазине списывают из банки категории (мечта) + cash как запас.
- Копилка: addToGoal из банки save; снятие — отдельное подтверждение + сдвиг срока.
- Ларёк: закупка у поставщика (2/2.5/3 ₡) → расстановка на полки (мини-игра) →
  цена на ценнике (прогноз BotBrain) → продажи за кассой (10 клиентов, timer 20с).
- Найм Милы: 80 ₡/день из расхода, списание в следующий день, если хватает.
- Участок: покупка 300 ₡, пассивный доход +10 ₡/день, продажа за 200 ₡ (с потерей).
- Итог дня: план/факт по банкам, отчёт (выручка, COGS, аренда, налог, зарплата).
- Нельзя уйти в минус; Финни не болеет как наказание.

5. КОНТРАКТЫ ДАННЫХ
------------------------------------------------------------------------
- PetEntity(id=1, name, bodyType 0..2, accessory 0..2, background 0,
  hunger, mood, energy, level 1..3)
- WalletEntity(id=1, cash, needPlan, wantPlan, savePlan, needFact, wantFact, saveFact)
- ShopEntity(id=1, stock, price, costPrice, cash, soldToday, revenueToday)
- TransactionEntity(day, kind INCOME/EXPENSE, category, amount, source)
- BotEntity(20 x WORKER, salary 800, wallet 200, loyalty 0)
- GoalEntity(id, title, targetAmount, currentAmount, completed)
- QuestEntity(id, topic PLANNING/SAVING/SPENDING, title, reward, completed, day)
- Каталог: 8 товаров (4 нужных: корм 40, вода 20, уход 25, подстилка 50;
  4 желаемых: мячик 60, бантик 35, картина 80, торт 90).

------------------------------------------------------------------------
