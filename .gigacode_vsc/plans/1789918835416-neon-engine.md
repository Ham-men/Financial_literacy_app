# План исправления ошибок и завершения UI

## Ошибки компиляции (2 шт)

### Ошибка 1: FoodScreen.kt:38 — неверный синтаксис viewModel
**Проблема:** `val vm: androidx.lifecycle.viewmodel.compose.viewModel(...)` — `viewModel()` это composable-функция, не тип.
**Исправление:** Заменить на:
```kotlin
val vm: PetViewModel = viewModel(factory = PetViewModel.factory(repo))
```
Добавить import: `import com.example.financialliteracyapp.ui.screens.pet.PetViewModel`

### Ошибка 2: PetScreen.kt:133 — `10px` вместо `10.dp`
**Проблема:** `border(10px, ...)` — Compose не знает `px`.
**Исправление:** Заменить на `border(10, ...)` — вспомогательная функция `.border(width: Int, ...)` сама конвертирует в `.dp`.
Удалить хелпер `border(width: Int, ...)` в конце файла — он дублирует встроенный `.border()` из Compose.
